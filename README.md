# Sistema de Gerenciamento de Farmácia

## 📋 Sobre o Projeto

Este projeto consiste no desenvolvimento de um banco de dados relacional para gerenciamento de uma farmácia, utilizando MySQL.

O sistema foi modelado para armazenar e gerenciar informações relacionadas a clientes, funcionários, medicamentos, fornecedores, vendas e demais operações essenciais de uma farmácia.

O projeto contempla desde a modelagem do banco até a criação de consultas SQL para extração e análise de dados.

---

## 🎯 Objetivos

- Aplicar conceitos de modelagem de banco de dados.
- Implementar relacionamentos entre entidades.
- Utilizar chaves primárias e estrangeiras.
- Desenvolver consultas SQL em diferentes níveis de complexidade.
- Simular um ambiente real de gerenciamento farmacêutico.
